Machine Learning Models

Understanding how Artificial Intelligence powers the Intelligent Academic Assistant for Saber 11

What is Machine Learning?

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from historical data and make predictions without being explicitly programmed with fixed rules. Instead of following predefined calculations, Machine Learning algorithms identify relationships among variables and use those relationships to estimate future results.

In this project, Machine Learning is used to analyze academic, family and socioeconomic factors and estimate the possible performance of a student in the Saber 11 examination.

Linear Regression

Linear Regression is a predictive algorithm that estimates a result by identifying linear relationships between input variables and the target variable.

How It Works

The model analyzes how variables such as academic performance, family factors and socioeconomic characteristics influence the final Saber 11 score.

Advantages
  • Simple to implement.
  • Fast prediction process.
  • Easy interpretation of results.
Limitations
  • Assumes linear relationships.
  • Less effective for complex patterns.

Random Forest Regression

Random Forest is an ensemble learning algorithm that combines multiple decision trees to generate more accurate and robust predictions.

How It Works

Instead of relying on a single decision process, Random Forest creates multiple decision trees, each producing a prediction. The final result is generated from the combined output of all trees.

Advantages
  • High predictive accuracy.
  • Excellent handling of complex relationships.
  • Reduced risk of overfitting.
Limitations
  • More computational resources.
  • Less interpretable than linear models.
