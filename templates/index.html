Project Name

Intelligent Saber 11 Score Predictor Using Machine Learning

Problem Statement

Many students take the Saber 11 examination without having an estimate of their future academic performance. This limits the identification of educational, socioeconomic, and family factors that may affect their final score.

Project Justification

This project applies Machine Learning techniques to historical educational data in order to predict Saber 11 results and provide useful insights for academic decision-making and performance analysis.

General Objective

Develop a Machine Learning web application capable of predicting the global Saber 11 score using academic, family and socioeconomic information.

Specific Objectives

  • Analyze historical Saber 11 datasets.
  • Prepare and preprocess educational data.
  • Train and evaluate Machine Learning models.
  • Develop an interactive Flask web application.
  • Create dashboards and statistical visualizations.
  • Support educational decision-making through predictive analytics.
