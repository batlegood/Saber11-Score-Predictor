Project Overview

Intelligent Saber 11 Predictor is a Machine Learning platform designed to estimate the academic performance of students before taking the Saber 11 examination.

The application analyzes educational, family, and socioeconomic information and uses a trained predictive model to estimate a student's global score.

In addition to score prediction, the platform provides educational statistics, visualizations, and insights based on real ICFES data.

How The System Works

The Intelligent Saber 11 Predictor uses Machine Learning techniques to estimate student performance using historical educational data obtained from ICFES.

Step 1: Data Collection

The user enters academic, family and socioeconomic information in the prediction form.

Step 2: Data Processing

The system validates and prepares the data before it is analyzed.

Step 3: Data Encoding

Text values are converted into numerical values using Label Encoders.

Step 4: Machine Learning Prediction

A trained Random Forest model analyzes the information and estimates the global score.
