Project Overview

Intelligent Saber 11 Predictor is a Machine Learning platform designed to estimate student performance before taking the Saber 11 examination.

The application analyzes academic, family and socioeconomic information and generates predictions using two Machine Learning algorithms: Random Forest Regression and Linear Regression.

The platform compares predictions generated by both models and evaluates their performance using statistical metrics such as R², MAE and RMSE.

In addition to score prediction, the system provides educational statistics, interactive charts and data analysis based on real ICFES records.

How The System Works

The Intelligent Saber 11 Predictor applies Machine Learning techniques to estimate student performance using historical educational data obtained from ICFES.

Step 1: Data Collection

The user enters academic, family and socioeconomic information through the form.

Step 2: Data Processing

The system validates and prepares all information.

Step 3: Data Encoding

Categorical values are transformed into numerical values.

Step 4: Model Comparison

Random Forest and Linear Regression generate and compare predictions.
