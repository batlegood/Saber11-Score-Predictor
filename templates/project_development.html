Project Development

Development process of the Intelligent Academic Assistant for Saber 11

Phase 1 - Project Planning

Objective

Define the educational problem, establish project goals, determine the system scope and identify the needs of students who will use the platform.

Activities
  • Problem identification.
  • Educational context analysis.
  • Requirement gathering.
  • Project scope definition.
Results

A clear project structure, defined objectives and an educational solution architecture focused on academic guidance.

Phase 2 - Dataset Collection

Objective

Collect and analyze reliable educational information capable of supporting the development of predictive models.

Activities
  • ICFES dataset exploration.
  • Identification of academic variables.
  • Identification of socioeconomic variables.
  • Selection of prediction targets.
Results

A structured educational dataset containing historical student performance information.

Phase 3 - Data Cleaning and Preparation

Objective

Improve data quality and ensure consistency before model training.

Activities
  • Missing value treatment.
  • Duplicate record removal.
  • Data normalization.
  • Data verification and validation.
Results

A clean, validated and reliable dataset ready for machine learning.

Phase 4 - Feature Engineering

Objective

Identify the most relevant factors affecting student performance.

Activities
  • Feature selection.
  • Predictor analysis.
  • Variable transformation.
  • Data preparation for training.
Results

An optimized dataset containing the most important variables for prediction.

Phase 5 - Linear Regression Development

Objective

Develop the first predictive model used as a baseline reference.

Activities
  • Dataset splitting.
  • Model training.
  • Prediction testing.
  • Performance evaluation.
Results

A functional predictive model capable of estimating Saber 11 scores.

Phase 6 - Random Forest Development

Objective

Improve prediction accuracy through an ensemble learning approach.

Activities
  • Model training.
  • Hyperparameter optimization.
  • Prediction analysis.
  • Model evaluation.
Results

A highly accurate predictive model capable of capturing complex educational patterns.

Phase 7 - Model Comparison

Objective

Compare predictive performance and identify the most reliable model.

Activities
  • R² evaluation.
  • MAE analysis.
  • RMSE analysis.
  • Comparative validation.
Results

Selection of the model with the best predictive capability.

Phase 8 - Web Application Development

Objective

Build an interactive educational platform accessible through the web.

Activities
  • Flask development.
  • Bootstrap interface implementation.
  • Responsive design integration.
  • User experience enhancement.
Results

A modern educational platform capable of interacting with users.

Phase 9 - PostgreSQL Integration

Objective

Provide secure authentication and cloud data storage.

Activities
  • User registration system.
  • Authentication module.
  • PostgreSQL integration.
  • Cloud database implementation.
Results

Secure user management and reliable cloud storage.

Phase 10 - Academic Assessment System

Objective

Develop a Moodle-style evaluation system capable of assessing academic knowledge and collecting socioeconomic information.

Activities
  • Question design.
  • Assessment categorization.
  • Knowledge evaluation process.
  • Socioeconomic profile collection.
Results

A complete academic assessment module integrated into the platform.

Phase 11 - Intelligent Recommendation System

Objective

Generate personalized educational guidance based on student performance.

Activities
  • Recommendation logic design.
  • Strength identification.
  • Weakness analysis.
  • Guidance generation.
Results

Personalized recommendations adapted to each student's profile.

Phase 12 - Testing and Validation

Objective

Verify reliability, functionality and prediction accuracy.

Activities
  • Functional testing.
  • Prediction validation.
  • Interface testing.
  • Performance optimization.
Results

A stable, validated and reliable educational platform.
