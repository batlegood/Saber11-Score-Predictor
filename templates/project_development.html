CRISP-ML Methodology

Development of the Intelligent Academic Assistant for Saber 11 following the CRISP-ML framework.

Phase 1 - Business and Data Understanding

Objective

Understand the educational problem, identify stakeholders, analyze available data and define measurable machine learning objectives.

Activities
  • Educational problem identification.
  • Analysis of the Saber 11 examination context.
  • Identification of stakeholders and beneficiaries.
  • Definition of business and machine learning objectives.
  • Dataset exploration and understanding.
Results

A clear definition of the Intelligent Academic Assistant for Saber 11, measurable project goals and identification of students as primary users.

Phase 2 - Data Engineering

Objective

Prepare and transform educational data to ensure quality and reliability before model training.

Activities
  • Dataset collection and exploration.
  • Missing value analysis.
  • Data cleaning and preprocessing.
  • Feature selection.
  • Data transformation and encoding.
Results

A structured and cleaned educational dataset ready for predictive modeling.

Phase 3 - Model Engineering

Objective

Design, train and optimize predictive models capable of estimating student academic performance.

Activities
  • Linear Regression implementation.
  • Random Forest implementation.
  • Model training.
  • Hyperparameter optimization.
  • Performance improvement.
Results

Multiple predictive models trained and optimized for educational score prediction.

Phase 4 - Model Evaluation

Objective

Evaluate model performance and select the most reliable predictive solution.

Activities
  • R² evaluation.
  • MAE analysis.
  • RMSE analysis.
  • Model comparison.
  • Validation process.
Results

Selection of Random Forest as the best-performing model according to evaluation metrics.

Phase 5 - Model Deployment

Objective

Deploy the selected machine learning model through a functional educational web platform.

Activities
  • Flask web application development.
  • Bootstrap interface implementation.
  • PostgreSQL integration.
  • Academic Assessment implementation.
  • Statistics Dashboard development.
  • Render cloud deployment.
Results

A fully functional educational platform capable of generating predictions, assessments and academic statistics.

Phase 6 - Monitoring and Maintenance

Objective

Ensure long-term reliability, usability and continuous improvement of the deployed solution.

Activities
  • Functional testing.
  • Prediction validation.
  • Statistics verification.
  • User feedback collection.
  • Model performance monitoring.
  • Future retraining planning.
Results

A stable and validated platform with documented procedures for maintenance, monitoring and future model updates.
